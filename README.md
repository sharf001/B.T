# BT — Behavior Tracker

تطبيق عربي RTL لتتبع الفواصل بين السلوكيات، دون خدمات خارجية أو اشتراكات.

## التشغيل

يتطلب Node.js 20 أو أحدث. لا توجد تبعيات تحتاج إلى تنزيل.

```sh
cd /workspace/B.T
npm start
```

افتح المنفذ **3000** من واجهة معاينة بيئة التطوير إن كانت متاحة. عند التشغيل على جهازك افتح `http://localhost:3000`. للنشر يمكن تقديم `index.html` ومجلد `src` عبر أي استضافة ملفات ثابتة. هذا خادم تطوير، ولا يوفّر مصادقة أو خدمة حسابات.

## التحقق

```sh
npm test
```

اختبارات الحسابات، إعادة ترتيب السجلات وتعديلها وحذفها، المستهدف التاريخي، توقيت القاهرة وتغيير التوقيت، والتحليل النصي.

اختبار المتصفح التكميلي في هذه البيئة (بعد تشغيل الخادم):

```sh
node scripts/browser-check.cjs
node scripts/backup-check.cjs
```

يستخدم Playwright المثبت في بيئة Codex وChromium النظام، ويختبر التسجيل والحفظ بعد التحديث والإدخال السابق والتعديل والحذف وتغيير المرحلة والأوامر النصية وعرض الهاتف. يتحقق الاختبار الثاني من التراجع وJSON وCSV ورفض الاستيراد غير الصالح. ينشئ الاختبار الأول صورًا في `artifacts/`؛ بياناته داخل متصفح اختبار معزول.

## سلوك البيانات والحساب

- يبدأ كل سلوك دون سجلات. أول تسجيل لا يحتسب فاصلًا سابقًا.
- المستهدف التالي = التقريب لأعلى للدقيقة للمستهدف المعتمد × (1 + النسبة). الافتراضي سُبع.
- يُحفظ مستهدف كل تسجيل ولا يتغير عند تعديل الخطة أو وقت التسجيل. تتغير الفواصل تلقائيًا عند تعديل التوقيت أو الحذف.
- الإدخال بأثر رجعي يختار آخر مستهدف كان ساريًا في وقت التسجيل؛ قبل بداية الخطة يُستخدم الفاصل الأساسي. لا ينشئ ذلك سجلات سابقة تلقائيًا.
- التقارير تحسب الفواصل المكتملة فقط. تنسب الفاصل إلى فترة تاريخ نهايته؛ المقارنة الأسبوعية والشهرية تعرض متوسطات لفترتين متساويتين في المدة، دون استنتاج تحسن من عدد التكرارات.
- وقت القاهرة يستخدم قاعدة التوقيت في المتصفح. الأوقات المحلية غير الموجودة أو المتكررة عند تغيير التوقيت تُرفض لتجنب التخمين.
- حدود الأسبوع السبت؛ بداية اليوم قابلة للتعديل. تمديد مرحلة انتهت يبدأ من الآن، وغير المنتهية من موعد مراجعتها.
- localStorage يحفظ البيانات لهذا الأصل والمتصفح والجهاز فقط. تغيير عنوان الاستضافة يغيّر مساحة الحفظ. صدّر JSON بانتظام؛ مسح بيانات المتصفح يمسح السجل. الاستيراد يستبدل البيانات بعد التحقق والتأكيد.
- لا مزامنة أو إشعارات خلفية أو PWA. يعمل دون API؛ يحتاج فتح الملفات من خادم ويب، ولا يعتمد العداد على استمرار تشغيل الصفحة.
- الأوامر المحلية محدودة بالصيغ الموضحة في الواجهة؛ تعرض معاينة قبل التنفيذ ولا تستخدم نموذج لغة أو خدمة مدفوعة.

لا توجد بيانات حقيقية مضمّنة أو تكرارات تجريبية. المثال الثالث يوم واحد افتراض قابل للتعديل.
